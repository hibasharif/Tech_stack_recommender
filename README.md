# Tech Stack Recommender

An interactive AI-inspired web application that helps users discover the most suitable technology stack for their projects based on their goals, experience level, and development preferences.

## 🌐 Live Demo

🔗 Live Project: https://claude.ai/public/artifacts/2f953a40-5751-4809-8f28-90a30d28a5af

## 📌 Features

* Interactive and responsive UI
* Smart technology stack recommendations
* Beginner-friendly experience
* Modern glassmorphism design
* Real-time recommendation flow
* Frontend-focused implementation
* Clean and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## 💡 Purpose of the Project

This project was created to help developers and students choose suitable technologies for their software projects in an easy and visually engaging way.

It demonstrates frontend development skills, UI/UX concepts, and interactive recommendation systems.

## 📸 Preview

The application provides a modern dashboard-like interface where users can explore recommended technologies based on their requirements.
